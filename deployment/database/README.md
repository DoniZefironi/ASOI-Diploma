# Дамп базы данных АСОИ

Эта папка содержит полный дамп базы данных PostgreSQL (схема + данные), а также
скрипты для резервного копирования и восстановления.

## Файлы

| Файл | Описание |
|---|---|
| `database_dump.sql` | Полный дамп БД `Curs` (44 таблицы, реальные данные пользователей, курсов, заявок и т.д.), снятый командой `pg_dump --clean --if-exists`. Содержит инструкции `DROP ... IF EXISTS` перед каждым `CREATE`, поэтому безопасно накатывается даже на базу, уже инициализированную из `init.sql`. |
| `init.sql` | Скрипт начальной инициализации БД (создание таблиц + минимальный набор seed-данных). Автоматически выполняется PostgreSQL-контейнером при первом старте на пустом volume (`docker-entrypoint-initdb.d`). |
| `restore_db.sh` | Скрипт восстановления дампа в контейнер `asoi_diploma_db`. |
| `backup_db.sh` | Скрипт создания нового дампа из работающего контейнера. |

## Восстановление дампа (полные данные)

1. Запустите контейнеры (см. главную инструкцию по развёртыванию — `Инструкция_по_развертыванию.md`):

   ```bash
   docker-compose up -d
   ```

2. Дождитесь, когда контейнер `asoi_diploma_db` станет `healthy`:

   ```bash
   docker ps
   ```

3. Восстановите дамп:

   ```bash
   cat deployment/database/database_dump.sql | docker exec -i asoi_diploma_db psql -U postgres -d Curs
   ```

   или с помощью готового скрипта:

   ```bash
   bash deployment/database/restore_db.sh deployment/database/database_dump.sql
   ```

4. Перезапустите backend, чтобы он переподключился к обновлённым данным:

   ```bash
   docker-compose restart backend
   ```

> Если дамп не восстанавливать, при первом запуске на чистом volume PostgreSQL
> автоматически выполнит `init.sql` — приложение тоже будет работать, но с
> минимальным набором данных.
